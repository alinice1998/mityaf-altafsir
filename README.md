# مطياف التفسير | Mityaf Al-Tafsir

<div dir="rtl">

أداة ويب مفتوحة المصدر لقراءة الأبعاد المنهجية للتفاسير القرآنية والنصوص التدبرية وملفات PDF، وترشيح التفسير الأنسب لحاجة القارئ في لحظة واحدة، مبنية كمثال عملي تطبيقي على نموذج اتخاذ القرارات **Gemini Decision 1** (`gemini-decision-1`) عبر **Gemini Decisions API**.

## المزايا
- **مقارنة التفاسير بالرادار الطيفي:** مقارنة حتى 3 تفاسير عربية معتمدة (السعدي، التحرير والتنوير، ابن كثير، القرطبي، الميسّر) عبر 6 محاور متدرجة (`score`) و5 مؤشرات ثنائية (`noul`) وتحديد الجمهور والطابع (`choice`).
- **ترشيح التفسير الأنسب:** ترتيب التفاسير المتاحة للآية حسب تفضيل القارئ (أسلوب سهل، هدايات وتربية، لغة وبلاغة، فقه وأثر) مع خيارات إضافية كشرح المفردات وتجنب التوسع في الخلافات.
- **تحليل النصوص المخصصة وملفات PDF:** لصق أي نص تدبري أو رفع ملف PDF مباشر مع حارس سياق يرفض المحتوى الخارج عن التفسير والتدبر.
- **مفتاح احتياطي تلقائي (Fallback Key):** يعمل الخادم بمفتاح `GEMINI_API_KEY` المدمج (مجاني عبر Google AI Studio) مع كاش دائم محلي، وإمكانية إدخال المستخدم مفتاحه الخاص من المتصفح عند امتلاء حصة الخادم.

</div>

## Quick Start (Local)

```bash
cp .env.example .env
# Add your free Google AI Studio key in .env -> GEMINI_API_KEY=...
npm install
npm run build
npm start
```

## Docker Deployment

```bash
cp .env.example .env
# Set GEMINI_API_KEY in .env
docker compose up -d --build
```
